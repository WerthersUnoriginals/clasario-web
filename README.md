# clasario.com

La web pública de [Clasario](https://clasario.com), planificador docente para Primaria y Secundaria. Es un sitio estático alojado en Netlify, que lo publica a cada `git push` a `main`.

| Archivo | Qué es |
|---|---|
| `index.html` | Portada, con el formulario de la lista de espera (Netlify Forms, `lista-espera`) |
| `gracias.html`, `404.html` | Página tras apuntarse y página de error |
| `condiciones.html`, `privacidad.html`, `aviso-legal.html` | Textos legales |
| `assets/` | Estilos, vídeo, imágenes y fuentes autoalojadas (sin recursos de terceros ni cookies) |
| `_redirects` | Redirección 301 de tizadocente.es a clasario.com |
| `robots.txt`, `sitemap.xml` | Para buscadores |

La aplicación (app.clasario.com) está en un repositorio privado aparte.
